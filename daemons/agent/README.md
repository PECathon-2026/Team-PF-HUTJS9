# daemons/agent/

Owner: **WIN**. The AI agent (spec §9, §7): it sees only sanitized pages, proposes one action at a time, and every action is checked before it can run. No network (`network_mode: none` once the compose fragment exists); it will talk to `core` and the gate over LNX's `plpy` channels. That plumbing isn't here yet: these are the pure-logic modules.

| Module | What |
|---|---|
| `plagent/actions.py` | Action JSON Schema (for constrained decoding) + strict parser. Kinds: click, fill, select, navigate, scroll, done. Fill values may only be placeholders. No read-back kind exists. |
| `plagent/validator.py` | Target exists/visible/enabled/right kind; no script URLs however disguised; allowed domains only; no userinfo/IP/look-alike hosts; no coordinate clicks. |
| `plagent/antirecon.py` | Placeholder binding (right placeholder, right type, right field), PII scan of model output, provenance hard rule (verified user quote required). |
| `plagent/pii.py` | The agent's own PII scanner (independent of `ml/` and `core`): normalises look-alikes, decodes base64/hex, catches partial hints. Findings never carry values. |
| `plagent/prompt.py` | Prompt with system / user-task / webpage fences, nonce-tagged; page text neutralised. |
| `plagent/risk.py` | Noisy-OR risk over the spec's five factors; allow / ask / deny; irreversible actions always ask. |
| `plagent/replay.py` | `pl.replay.v1` cassette format + replay provider (fails closed when exhausted). |
| `plagent/agent.py` | One step: prompt -> model -> checks in a fixed order -> execute / approval / blocked, each with a rule ID. |

Cassettes: `cassettes/benign/` and `cassettes/malicious/`, generated by `cassettes/build_cassettes.py` against `fixtures/checkout_page.json`.

Tests (until the dev image exists): `tools/win/pyrun.sh daemons/agent uv run pytest`.
